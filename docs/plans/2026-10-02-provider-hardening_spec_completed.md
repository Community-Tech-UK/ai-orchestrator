## Capability decisions

Claude native escalation and reactive compaction must retain native ownership where verified; installed behavior remains subject to its recorded evidence check. Harness must not stack an in-place retry around it. Xiaomi reasoning cap must be proven supported before adding a knob; unsupported controls are an explicit implementation limitation, not a fabricated setting. Provider transcript sanitization similarly needs a real API and must fail closed. Installed OpenCode 1.18.34 was verified through a disposable native API and actual loopback fake-provider request: compacted tool output and attachments are excluded and the cleared-result marker is retained. MiMo's [official Chat API](https://mimo.mi.com/docs/en-US/api/chat/openai-api) documents `max_completion_tokens` as the combined visible-output and reasoning cap. Only an explicitly selected token-plan Pro model receives the budget; auto/default selection remains native and is not claimed capped. The budget constrains model options, output limit, direct variants and applicable numeric agent options to one scalar, preserving the smaller explicit overlay/effective caps and native context. Native merged model/mode determines agent scope, including inherited custom subagents; unrelated subagents retain their budgets. Before each spawn, two private bounded native config probes resolve original and prepared overlays using the same configured sandbox. Projections retain only numeric limits, safe scope identifiers, permission keys/actions and a plugin-presence marker, never credential-bearing options or permission pattern values. The final probe verifies the effective cap and doom-loop permission ordering; discovery or verification failure refuses startup. A scoped MiMo session also refuses startup if native ACP model selection is rejected. Scoped MiMo startup rejects external plugins, cross-model primary numeric overrides and ambiguous auxiliary-agent caps because enforcement cannot be proved safely; unrelated selected models retain native budgets and plugins. An installed-CLI request smoke using the production helper proves `max_completion_tokens=16384` reaches the wire. The earlier `max_tokens` smoke alone did not prove vendor combined-budget semantics. Independent reasoning control remains unsupported. Native `repetition_truncation` is classified as a repetition cutoff when preserved by the CLI; legacy collapse detection remains the fallback when a CLI drops native finish metadata.
