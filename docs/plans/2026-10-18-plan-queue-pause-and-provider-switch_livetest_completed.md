## Scratch setup

Create a temporary Git repository on `main` with one committed source file and two untracked `*_plan.md` documents asking workers to make small distinct changes and record as-built notes. Configure worker slots to one initially so Pause can be observed. Keep normal safety/account settings; use accounts allowed for automatic work. On the Plan Queue page start a Plans run scoped to this repository. Record selected worker/checker providers and the initial spend label. Never use production plans for these checks.

## 1. Pause a live worker and Resume

- [x] While its worker is producing output, press the run's Pause button. Expected within seconds: its queue worker/triage/checker sessions stop, status is Paused, held documents show Paused, the same branch and working folder remain. The working folder's `git status --porcelain` is clean and its log has the pause checkpoint if there were edits. An unresolved merge instead remains uncommitted on disk. No further spending is reported once in-flight provider usage has settled.
- [x] Press Resume. Expected: a fresh worker on the same branch and working folder uses a resume prompt, continues from existing work and does not reinstall an already present dependency folder.

Why deferred: requires real running provider processes and final provider usage reporting, which scripted queue instances cannot establish.

## 2. Pause a checker

- [x] Let a worker finish and a checker start; press Pause during checking. Expected: checker stops, its edits are discarded back to the checkpoint, document waits as Paused, and round/errored-round counters do not increase.
- [x] Press Resume. Expected: a new checker judges the saved work again without a worker fix turn caused by the interrupted check.

Why deferred: confirms termination of a real checker process and its provider session; checkpoint/reset behavior is already exercised with real Git in automated tests.
