## Problem (evidence)

Work Finder queue items parked as `verifier-unreliable` all day on 27 October. Reviewer transcripts (`claude-cli-profiles/*/projects/-Users-suas-work-communitytech-work-finding--worktrees-queue-*/*.jsonl`) and `app.log` show three separate causes:

1. **Discovery.** Reviewers searched Claude's native ToolSearch for `plan_queue_report_verdict`, which lives behind `orchestrator_tool_search`/`_describe`. The running build's verifier prompt has no discovery steps. Already fixed in source, not installed: [queue repair application](2026-10-27-queue-repair-application_plan_completed.md).
2. **Turn ends during gates.** Reviewers start long gates in the background, write "I'll continue when they finish" and end the turn. `PlanQueueItemFlow.finishVerification` (`plan-queue-item-flow.ts`) stops the verifier on its first turn completion and counts an errored round; two park the item.
3. **Wrong model.** For an `unchanged` checker, `modelOverrideOptionFor` (`review/checker-plan.ts`) returns no model, so the verifier session inherits the provider's remembered default model rather than James's configured reviewer model (`crossModelReviewModelByProvider`, Claude `sonnet`). Verifier selection logged `sonnet`; transcripts show `claude-haiku-5-5` from 10:30 to 12:27 UTC, `opus` at 13:06. The headless review host already falls back to the configured model (`review-execution-host.ts` `dispatchReviewerPrompt`); the Plan Queue spawn does not.

## As built

Verifier prompts tell the reviewer its review ends with its turn and how to reach `plan_queue_report_verdict` through Harness discovery. A verifier that ends a clean turn without a verdict gets up to two reminder turns (`plan-queue-verifier-reminder.ts`), started without holding the item lock; a failed reminder turn counts the round as before, except during app quit. Pause, tree changes and failures are never reminded. Verifier selection passes an unchanged checker's configured reviewer model explicitly; Antigravity uses the review host's quota-aware plan but never a fallback from the worker's model family.
