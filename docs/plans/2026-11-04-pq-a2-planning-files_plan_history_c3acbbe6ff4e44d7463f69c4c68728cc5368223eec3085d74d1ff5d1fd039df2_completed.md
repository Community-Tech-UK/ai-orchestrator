4. **Identical bytes** at the root count as moved without a record, so a later update of that file goes beside rather than in place (conservative).
5. **Untracked only.** A planning file the worker has staged (`git add`) is tracked from git's point of view, so it is not moved; if it reaches the branch, landing still refuses it as before and the new `buildActiveDocumentsPrompt` text tells the worker what to do.
