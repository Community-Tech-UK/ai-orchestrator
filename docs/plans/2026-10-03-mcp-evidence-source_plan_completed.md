## Review focus

1. Ownership shifts or missing instance/chat never authorize another conversation.
2. Concurrent calls and provider buffering cannot borrow another invocation's identity or omit queued writes.
3. Capture errors reveal no raw output, arguments, secrets or storage error content.
4. Failed persistence/provenance checks execute no mutation; post-execution capture failures explicitly warn against blind retries.
5. Windows acceptance uses newly executed tests/browser observations and cleans up only owned resources.
