Account rules

Keep an account away from Plan Queue sessions and automation runs. Use last: they use it only when no other account can run (a Copilot automation always uses its folder's Copilot account unless it is set to Never use). Never use: no queue session or new automation session starts, switches or wakes on it, and a queue session already running on it is stopped and restarted on another account. Sessions you open yourself, loops and automations that wake one of your existing sessions are not affected.
