# Vendored webfonts — licensing

The renderer's two typefaces are vendored into this directory rather than
loaded from Google. Both are licensed under the **SIL Open Font License,
Version 1.1**, which permits redistribution (including bundling inside an
application) provided the copyright notice and licence text travel with the
font files. That is what this directory is for.

## Vendored files

- `jetbrains-mono-*.woff2` — JetBrains Mono, the technical/monospace face.
  Copyright 2020 The JetBrains Mono Project Authors.
  Upstream: https://github.com/JetBrains/JetBrainsMono
  Licence: `OFL-JetBrainsMono.txt`

- `ibm-plex-sans-*.woff2` — IBM Plex Sans, the UI/body face.
  Copyright © 2017 IBM Corp. with Reserved Font Name "Plex".
  Upstream: https://github.com/IBM/plex
  Licence: `OFL-IBMPlexSans.txt`

Each family ships as one variable woff2 per unicode subset (latin, latin-ext,
cyrillic, cyrillic-ext, greek, vietnamese). A single file covers all four
weights the design system uses, because both families are variable fonts.

## Reserved Font Names

IBM Plex is released with the Reserved Font Name "Plex". Under OFL clause 3 a
modified version may not be distributed under that name. These files are
unmodified upstream binaries as served by Google Fonts, so the restriction is
satisfied by not renaming or re-editing them. If a subset or modification is
ever generated locally, it must be renamed before redistribution.

## How these files got here

Generated by `scripts/vendor-google-fonts.js`, which downloads the woff2
subsets and both licence texts and regenerates `../_fonts.scss`. Do not
hand-edit the fonts, the `OFL-*.txt` files, or `_fonts.scss`; re-run the script
instead. This file is hand-written and is deliberately left alone by it.

`scripts/__tests__/renderer-fonts-self-hosted.spec.ts` guards the arrangement:
it fails if a stylesheet reaches out to a remote font host again, if the CSP
re-admits one, or if a declared face has no matching file on disk.
